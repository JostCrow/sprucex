SpruceX LLM.txt
Version: 1.2.0
Status: Active development.

Overview

SpruceX is a lightweight reactive HTML framework combining Alpine-style
declarative reactivity with HTMX-style hypermedia requests. It uses `sx-*`
attributes on plain HTML, supports fine-grained dependency tracking, custom
element-scoped directives, Shadow DOM embeds, and strict-CSP evaluation.

Install / Entry Points

- Browser bundle: `/dist/sprucex.js` or `/dist/sprucex.min.js`
- Full package: `import SpruceX from "sprucex"` (`lib/sprucex.mjs`, `lib/sprucex.cjs`, `lib/sprucex.d.ts`)
- Tree-shakeable core (no auto-init, no bundled integrations): `import SpruceX from "sprucex/core"`
- Optional subpath integrations: `sprucex/sortable`, `sprucex/gridstack`

Quick Start

<script src="/dist/sprucex.js"></script>

<div sx-data="{ count: 0 }">
  <button sx-on:click="count++">+1</button>
  <span sx-text="count"></span>
</div>

Core Directives

- `sx-data`: component root state (object/function/factory expression)
- `sx-text`: write `textContent` (no-op guarded)
- `sx-html`: write `innerHTML` (no-op guarded; does not wipe unchanged subtrees)
- `sx-show`: toggle visibility while preserving inline `display`
- `sx-if`: conditional mount/unmount on `<template>` (tears down nested state & directives)
- `sx-for`: keyed/unkeyed loop on `<template>` (`sx-key` recommended for reorders)
- `sx-bind:<attr>`: bind attributes (preserves `aria-*="false"`, syncs live `value`/`checked`/`indeterminate`)
- `sx-class`: conditional classes while preserving original classes
- `sx-style`: dynamic inline styles (object with camelCase / `--css-vars`, or string)
- `sx-cloak`: stripped automatically after initial render
- `sx-init`: one-time initialization statement on an element
- `sx-effect`: fine-grained reactive side effect on an element
- `sx-toggle`: toggle a boolean state key on click
- `sx-model`: two-way binding for inputs, textareas, single & `<select multiple>`
  Modifiers: `.trim`, `.number` (preserves empty string), `.boolean`, `.lazy`, `.debounce.<ms>`, `.debounce-ms="N"`
- `sx-ref`: register element on `$refs`
- `sx-memo`: cache `sx-text` / `sx-html` based on dependency keys
- `sx-local`: persist component state to `localStorage` (microtask-batched)
- `sx-lazy`: defer component init until element enters viewport (works on swapped/loop roots too)
- `sx-error-fallback`: fallback expression if a binding throws
- `script[sx-init-data]`: embedded JSON for identifier-style `sx-data` roots

Expressions & Magic Helpers

- `$event`: current DOM event in handlers
- `$el`: current DOM element
- `$refs`: object of `sx-ref` elements
- `$store(name)`: access global stores
- `$emit(name, detail)`: emit component-scoped custom event (triggers local `sx-trigger`)
- `$dispatch(name, detail)`: dispatch bubbling DOM `CustomEvent` (child-to-parent & cross-component)
- `$nextTick(fn?)`: wait until next batched render flush
- `$parent`: parent `sx-data` component state (if nested)
- `$index`: default loop index inside `sx-for`

Reactivity & Large-Dataset Helpers

- Plain objects and arrays are deeply reactive; built-ins (`Date`, `Map`, `Set`,
  `TypedArray`, DOM nodes, and custom class instances) stay unproxied.
- Own read-only getters on `sx-data` are automatically memoized via fine-grained tracking.
- `SpruceX.markRaw(obj)`: exclude large datasets/instances from deep proxying
- `SpruceX.toRaw(proxy)`: unwrap reactive proxy back to raw target
- `SpruceX.shallow(obj)`: shallow reactivity (only top-level property replacements trigger updates)
- `SpruceX.computed(fn)` / `SpruceX.effect(fn)` / `SpruceX.stop(runner)`: standalone reactive primitives
- Watchers in `sx-data`: `watch: { count(next, prev) {}, 'user.name'(next, prev) {} }` (path-aware)
- Lifecycle hooks in `sx-data`: `init()`, `mounted()`, `destroyed()`
- Global stores: `SpruceX.store(name, value, { persist, syncTabs })`, `SpruceX.removeStore(name)`
- Named factories: `SpruceX.data(name, factory)`

Event Handling

- `sx-on:<event>` attaches handlers (lazy root delegation)
- Modifiers: `.prevent`, `.stop`, `.self`, `.once`, `.outside`, `.window`, `.document`,
  `.passive`, `.capture`, `.debounce.<ms>`, `.throttle.<ms>`
- Keyboard modifiers: `.ctrl`, `.alt`, `.shift`, `.meta`, `.cmd` combinable with key names
  and aliases (`.enter`, `.esc`, `.space`, `.up`, `.down`, `.left`, `.right`, `.del`, etc.)

Network Directives

- Methods: `sx-get`, `sx-post`, `sx-put`, `sx-patch`, `sx-delete`
- Triggers: `sx-trigger` (supports `load`, `input.debounce.300`, and cross-component
  `event from:window|document|#selector`), `sx-trigger-debounce`
- Targeting & swaps: `sx-target`, `sx-swap` (`innerHTML`, `outerHTML`, `before`, `after`,
  `prepend`, `append`, `morph`, `delete`, `none`), `sx-select`, `sx-push-url`, `sx-replace-url`
- URL/body/headers: `sx-vars` (URL-encoded `${key}`), `sx-params` (`URLSearchParams`),
  `sx-body`, `sx-body-type` (`json`/`form`), `sx-headers`, `sx-include`
- State targets: `sx-json-into`, `sx-json-into.shallow` (marks payload raw),
  `sx-loading-into`, `sx-error-into` (includes HTTP `status` and parsed `body`)
- UX & flow: `sx-disable-while-request`, `sx-text-while-request`, `sx-confirm`,
  `sx-optimistic`, `sx-revert-on-error`, `sx-cancel-previous`,
  `sx-poll` (visibility-aware; pauses when `document.hidden`), `sx-poll-while`, `sx-poll-background`

Global Configuration

SpruceX.config({
  baseUrl: 'https://api.example.com',
  csrfCookieName: 'csrftoken',
  csrfHeaderName: 'X-CSRFToken',
  credentials: 'same-origin',
  headers: () => ({ Authorization: 'Bearer ...' }),
  beforeRequest(ctx) { /* mutate ctx.url/headers or return false to cancel */ },
  afterResponse(ctx) { /* inspect ctx.response */ },
  csp: false,
  debug: false,
  viewTransitions: false,
});

Navigation, Shadow DOM & Portability

- `sx-page`, `sx-page-ignore`, `sx-page-transition`, `sx-boost`, `sx-boost-on`, `sx-key`, `sx-preserve`
- `SpruceX.init(root?)`: initialize document, Element, or ShadowRoot with scoped auto-cleanup
- `SpruceX.mount(el, options?)` / `SpruceX.unmount(el)`
- `SpruceX.inspect(root?)`, `SpruceX.nextTick(fn?)`
- `SpruceX.navigate(url)`, `SpruceX.prefetch(url)`, `SpruceX.clearCache()`, `SpruceX.morph(target, source)`
- `window.SpruceXBoot = { initTheme() {}, autoInit: true }`

Element-Scoped Directives (Recommended for Charts & Widgets)

SpruceX.directive("chart", (el, { evaluate, effect, cleanup, modifiers }) => {
  const chart = createChart(el, SpruceX.toRaw(evaluate()), { modifiers });
  effect(() => chart.update(SpruceX.toRaw(evaluate())));
  cleanup(() => chart.destroy());
});
